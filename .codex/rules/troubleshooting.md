# Troubleshooting Rules

- Capture the exact failing command and output before changing code or config.
- Check local evidence first: logs, process state, open ports, generated files, config, versions, and recent edits.
- If the same failure repeats, stop retrying blindly and narrow the failure mode.
- For WSL, USB, serial, camera, microscope, robotics, driver, library, or vendor SDK issues, verify current upstream documentation or issue trackers when local evidence is insufficient.
- Make the smallest targeted fix or next diagnostic step.
